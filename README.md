# 弗一把 · 猜选手（AstrBot 插件）

在 QQ 群里玩 CS:GO / CS2 Major 选手猜谜。开局后每人独立一局，猜一位选手，机器人按
**国家 / 赛区 / 战队 / 年龄 / 位置 / Major 冠军数 / Major 出场数 / 现役状态** 八项给出
`🟩 一致`、`🟨 接近`、`🟥 不符` 的反馈，8 次机会内猜中即胜。

仓库地址：<https://github.com/weadee/astrbot_plugin_friberg_guess>

灵感来自 [弗一把 csgofriberg](https://shnlfriberg.online)（开源 AGPL-3.0），本插件为独立实现，
未复制其源码，仅对齐了判定规则与属性口径。

## 玩法示例

```
用户：弗一把
Bot ：🎮 弗一把 · 猜 CS Major 选手
      难度：普通（全部选手 646 人）｜机会：8 次｜限时 30 分钟
      直接发选手昵称就能猜（大小写不限，可以只写前几个字母）
      其它指令：提示 · 放弃 · 战绩 · 排行 · 图鉴 <名字>
      🟩 完全一致　🟨 接近　🟥 不符　↑/↓ 答案更大/更小

用户：s1mple
Bot ：第 1/8 猜｜s1mple
      🟨国家 乌克兰　🟩赛区 欧洲　🟥战队 BC.Game
      🟨年龄 28↓　🟩位置 AWPer
      🟥冠军 1↑　🟥出场 14↓　🟩状态 现役
      还剩 7 次机会
```

`↑` / `↓` 表示**答案**比猜的这个数值更大 / 更小；`🟨` 表示数值差在容差内
（年龄 ±3 岁，Major 冠军与出场数 ±1）。

## 指令

| 指令 | 说明 |
| --- | --- |
| `弗一把` / `弗一把 入门\|简单\|普通` | 开一局（也认「猜选手」别名） |
| 直接发选手昵称，或 `猜 niko` | 提交一次猜测 |
| `提示` | 随机揭示一项属性值，每局默认 2 次 |
| `放弃` | 结束本局并公布答案（也认「结束」「认输」） |
| `战绩` | 自己的胜场与平均猜测次数 |
| `排行` | 本群胜场榜 |
| `图鉴 s1mple` | 查选手资料 |
| `弗一把帮助` | 玩法说明 |

群里不用加 `/` 也能开局和猜，加了也没问题；私聊同样适用——私聊里直接发「弗一把」
或选手昵称即可，不需要唤醒前缀。

## 排错

**私聊没反应？**

1. 先确认机器人本身能收到私聊（在私聊里发 `/sid` 看有没有回）；
2. 确认插件在 WebUI 的插件列表里是「已启用」状态；
3. 确认日志里有 `弗一把 · 猜 CS Major 选手` 的加载信息——没有就是没加载成功。

本插件在私聊里不依赖唤醒前缀：`弗一把`、`/弗一把`、`猜 niko`、`提示` 都能直接用。

**群里要加前缀才能用？**

不需要。插件自带裸口令兜底：`弗一把`、`提示`、`放弃`、`战绩`、`排行`、`图鉴 xxx`
不带前缀都认。若你的机器人配了自定义唤醒词，也仍然走兜底逻辑。

**一句话被当成猜测了？**

只有「整条消息就是一个选手昵称」才会提交，且必须有一局进行中；`提示`/`放弃` 在没有对局时
保持沉默，不会在群里乱回。

## 安装

1. 把整个 `astrbot_plugin_friberg_guess` 文件夹放进 `AstrBot/data/plugins/`；
2. 在 WebUI「插件管理」里点重载（或重启 AstrBot）；
3. 插件配置里可调次数、限时、难度、提示开关。

也可以在 WebUI 的插件页填入仓库地址安装，后续能直接在面板里更新：

```
https://github.com/weadee/astrbot_plugin_friberg_guess
```

无第三方依赖，纯标准库。

## 配置项（`_conf_schema.json`）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `max_attempts` | 8 | 每局机会数 |
| `default_difficulty` | `normal` | 默认难度：入门 322 人 / 简单 384 人 / 普通 646 人 |
| `timeout_minutes` | 30 | 单局限时，超时自动公布答案；填 0 不限时 |
| `free_text_guess` | 开 | 允许不用指令直接发昵称猜 |
| `enable_hint` / `hint_limit` | 开 / 2 | 提示功能与次数 |
| `show_legend` | 开 | 第一次猜测附带颜色图例 |
| `at_sender` | 开 | 群聊反馈时 @ 猜的人 |

## 数据

- `data/players.json`：646 位 CS Major 选手，字段为
  `nickname / nationality / region / team / team_history / age / role / major_championships / major_appearances / difficulties / is_active`，
  快照版本 `2026-08-04`。
- 数据整理自社区公开选手库（弗一把官网所用的 `csgo-major-db` 镜像仓库、`friberg-helper`
  的同源导出），判定口径参照 `shnlfriberg/csgofriberg` 的 `compareGuess`。
- 想更新选手库：直接替换 `data/players.json`（保持同样的字段名），重载插件即可；
  插件启动时会打印加载人数到日志。

已知数据限制：

- `team_history` 当前快照为空，所以「战队」只会出现 `🟩`（同队）或 `🟥`，不会出现
  「曾效力」的 `🟨`。填上履历后规则自动生效。
- 年龄、战队为快照值，转会或生日后会有偏差，可用 `图鉴` 核对。

## 自测

```bash
python tests/selftest.py
```

自由文本猜测、存档恢复与超时结算，共 30 项断言。
