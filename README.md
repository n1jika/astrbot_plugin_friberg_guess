# 猜选手 · 弗一把 / 足一把 / 撸一把 / 瓦一把（AstrBot 插件）

在 QQ 群里玩四种「猜选手」：CS:GO / CS2 Major 选手、足球球员、LoL 职业选手、瓦罗兰特职业选手。
一套对局骨架（开局、计时、提示、战绩、排行、存档）配四个题库，各自按自己的属性格给反馈。

仓库地址：<https://github.com/weadee/astrbot_plugin_friberg_guess>

## 四个题库

| 命令 | 题库 | 人数 | 机会 | 对比属性 |
| --- | --- | --- | --- | --- |
| `弗一把` | CS Major 选手 | 646 | 8 | 国家 · 赛区 · 战队 · 年龄 · 位置 · Major 冠军 · 出场 · 状态 |
| `足一把` | 足球球员 | 1141 | 10 | 国籍 · 联赛 · 俱乐部 · 位置 · 出生年 · 号码 · 欧冠 · 世界杯届数 · 世界杯冠军 |
| `撸一把` | LoL 职业选手 | 2427 | 8 | 位置 · 国家 · 大洲 · 年龄 · 状态 |
| `瓦一把` | 瓦罗兰特选手 | 543 | 8 | 国籍 · 赛区 · 战队 · 身份 · 职责 · 年龄 · 大师赛参赛 · 大师赛冠军 · 冠军赛参赛 · 冠军赛冠军 |

## 玩法示例

```
用户：足一把
Bot ：⚽ 足一把 · 猜足球球员
      难度：普通（核心球员 693 人）｜机会：10 次｜限时 30 分钟
      直接发选手名就能猜（大小写不限，可以只写前几个字母）
      其它指令：提示 · 放弃 · 战绩 · 排行 · 图鉴 <名字>
      其它题库：弗一把 · 撸一把 · 瓦一把
      🟩 完全一致　🟨 接近　🟥 不符　↑/↓ 答案更大/更小

用户：哈兰德
Bot ：第 1/10 猜｜哈兰德（Erling Haaland）
      🟨国籍 挪威　🟥联赛 英超
      🟥俱乐部 曼城　🟥位置 前锋
      🟥出生年 2000↓　🟥号码 9↓
      🟩欧冠 1　🟨世界杯 1↑
      🟥世界杯冠军 0↑
      还剩 9 次机会
```

`↑` / `↓` 表示**答案**比猜的这个数值更大 / 更小。

各题库的「接近」判定：

- **CS**：同赛区算国家接近；曾效力过答案所在战队算战队接近；年龄 ±3；冠军/出场 ±1
- **足球**：同大洲算国籍接近（双国籍互认直接算对）；出生年 ±2；号码 ±2；欧冠 ±1；世界杯届数 ±1；世界杯夺冠数必须一致
- **LoL**：位置、状态相同才算一致；国家相同为绿、同大洲为黄；年龄 ±2
- **瓦罗兰特**：国籍同大洲为黄；战队同赛区为黄；身份要「状态 + 是否一线队」两项都对才绿
  （只要有一方退役就只比状态）；职责完全相同为绿、有交集为黄；大师赛参赛 ±2、冠军赛参赛 ±1；
  年龄与两个冠军数只 ↑/↓ 不给黄

### 瓦一把（瓦罗兰特）

```
用户：瓦一把
Bot ：🎯 瓦一把 · 猜瓦罗兰特选手
      难度：易（热门 150 人，含退役与自由人）｜机会：8 次｜限时 30 分钟
      直接发选手名就能猜（大小写不限，支持中文名与别名）

用户：ZmjjKK
Bot ：第 1/8 猜｜ZmjjKK
      🟥国籍 中国　🟥赛区 VCT CN　🟥战队 EDward Gaming
      🟥身份 现役　🟨职责 决斗　🟥年龄 22↑
      🟥大师赛参赛 7↓　🟥冠军赛参赛 4↓
      🟥大师赛冠军 0↑　🟥冠军赛冠军 1↓
      还剩 7 次机会
```

**默认「易」＝热门 150 人**，选法是先收站点热门池里的**全部退役老将与自由人**
（TenZ、ScreaM、ShahZaM、Boostio、carpe、Sayaplayer、ANGE1 …… 19 位退役 + 7 位自由人），
其余按站点热度分补齐到 150 人，覆盖 TenZ、ZmjjKK、Boaster、Derke、aspas 等名号。
题库本身仍是完整的 543 人，**池外那 393 人照样能猜**，只是不会成为答案。

想更难：`瓦一把 中`（有大师赛/冠军赛履历的 314 人）、`瓦一把 难`（全部 541 人可出题）。

## 指令

| 指令 | 说明 |
| --- | --- |
| `弗一把` / `足一把` / `撸一把` / `瓦一把` | 开一局，可带难度词 |
| 直接发选手名，或 `猜 xxx` | 提交一次猜测 |
| `提示` | 随机揭示一项属性，每局默认 2 次 |
| `放弃` | 结束本局并公布答案（也认「结束」「认输」） |
| `战绩` | 当前题库的胜场与平均猜测次数 |
| `排行` | 本群当前题库的胜场榜 |
| `图鉴 哈兰德` | 查选手资料（先查当前题库，找不到再翻其它题库） |
| `猜选手帮助` | 玩法说明 |

### 难度：易 / 中 / 难

四个题库共用一套难度词，开局时临时指定，或在配置里设默认值：

| 难度 | CS | 足球 | LoL | 瓦罗兰特 |
| --- | --- | --- | --- | --- |
| `易`（默认） | 最火 200 人 | 知名 300 人（含退役与小联赛巨星） | 中韩选手 782 人 | 热门 150 人（含退役、自由人） |
| `中` | 主流选手 384 人 | 五大联赛 925 人 | 现役选手 1904 人 | 有国际赛履历 314 人 |
| `难` | 全部 646 人 | 全部 1141 人（含非五大与退役） | 全部 2393 人（含退役） | 全部 541 人 |

用法：`弗一把 难`、`足一把 易`、`撸一把 中`、`瓦一把 难`。旧难度词仍然兼容：`入门`→易、
`简单`→中、`普通`/`地狱`→难。

**难度只管「答案」，不管「你能猜谁」**：题库永远是完整的，难度决定答案从多大的池子里抽。

| | 题库（都能猜） | 易（默认） | 中 | 难 |
| --- | --- | --- | --- | --- |
| 弗一把 | 646 | 200 | 384 | 646 |
| 足一把 | 1141 | 300 | 925 | 1141 |
| 撸一把 | 2427 | 782 | 1904 | 2393 |
| 瓦一把 | 543 | 150 | 314 | 541 |

也就是说：`足一把` 的答案来自 300 人，但池外那 841 人照样能提交、照样有完整棋盘反馈，
只是不会成为答案。同名选手（撸一把有 16 个重名，如两个 Ace；瓦一把有 1 个，`Klaus`）
不作为答案，避免猜中了判到另一个人身上。

### 弗一把的默认池：最火 200 人

不带难度发 `弗一把`，**答案**从「最火 200 人」里出；**题库仍是 646 人** —— 猜谁都可以，
池外那 446 人照样能提交、照样有棋盘反馈，只是不会成为答案。

- **135 位点名名单**：s1mple、ZywOo、NiKo、device、dupreeh、olofmeister、GeT-RiGhT、f0rest、
  NEO、markeloff、coldzera、FalleN、karrigan、donk、m0NESY、Twistzz、EliGE、Stewie2K……
- **65 位按履历补齐**：只看 Major 冠军数 > 出场届数 > 是否现役，不做「冷门/热门」的主观筛选。
- **教练不算答案**：题库里有 76 条教练记录，默认池全部排除，避免出现「猜中了也想不到」的情况。
- 实际构成：现役 151 / 退役 49；拿过 Major 冠军的 69 人（其中 22 人多冠）；Rifler 155 / AWPer 45；
  含 8 位中国选手（JamYoung、somebody、Summer、Westmelon 等）。

想更难就用 `弗一把 中`（主流 384）或 `弗一把 难`（全部 646）。名单在 `main.py` 的 `CS_FAMOUS`，
取数逻辑在 `_cs_famous_pool()`。

### 仅私聊模式

配置里把「仅私聊可用」打开后，群里发指令和选手名都不会响应，只能私聊玩——
适合不想让群里被刷屏的场景。

群里和私聊都不需要唤醒前缀：`弗一把`、`/弗一把`、`猜 niko`、`提示` 都能直接用。
`提示` / `放弃` 在没有进行中对局时保持沉默，不会在群里乱触发。

## 安装

想省事就直接下 Releases 里的安装包（zip 内已含插件目录，解压即用）：

<https://github.com/weadee/astrbot_plugin_friberg_guess/releases/latest>

手动安装：

1. 把整个 `astrbot_plugin_friberg_guess` 文件夹放进 `AstrBot/data/plugins/`；
2. 在 WebUI「插件管理」里点重载（或重启 AstrBot）；
3. 插件配置里可调次数、限时、难度、各题库开关。

也可以在 WebUI 插件页填仓库地址安装，后续能直接在面板里更新：

```
https://github.com/weadee/astrbot_plugin_friberg_guess
```

无第三方依赖，纯标准库（抓题数据用的脚本在仓库外，插件运行时不联网）。

## 配置项（`_conf_schema.json`）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `difficulty` | `易` | 默认难度：易 / 中 / 难（只影响答案池，不影响能猜谁） |
| `private_only` | 关 | 仅私聊可用，群里不响应 |
| `max_attempts` | 0 | 0 = 按题库默认（CS 8 / 足球 10 / LoL 8 / 瓦一把 8）；填正数则统一 |
| `timeout_minutes` | 30 | 单局限时，超时公布答案；0 不限时 |
| `enable_cs` / `enable_football` / `enable_lol` / `enable_valorant` | 开 | 分题库开关 |
| `free_text_guess` | 开 | 允许直接发名字猜 |
| `enable_hint` / `hint_limit` | 开 / 2 | 提示功能 |
| `show_legend` | 开 | 第一次猜测附带图例 |
| `at_sender` | 开 | 群聊反馈时 @ 人 |

## 数据

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `data/players.json` | 646 位 CS Major 选手 | 社区整理版本（快照 2026-08-04） |
| `data/football_players.json` | 1141 位足球球员 | 足一把 `players.js`（2026-27 赛季初） |
| `data/lol_players.json` | 2427 位 LoL 选手 | [Liquipedia](https://liquipedia.net/leagueoflegends) 选手页 Infobox，用 `tools/build_lol_db.py` 生成 |
| `data/valorant_players.json` | 543 位瓦罗兰特选手 | [瓦一把](https://wayiba.com) 站点 `players.generated.json`，用 `tools/build_valorant_db.py` 生成 |

- CS 判定口径参照开源项目 [csgofriberg](https://github.com/shnlfriberg/csgofriberg)（AGPL-3.0）。
- 足球判定口径参照 [足一把](https://www.zuyiba.net) 页面里的 `compare` 实现。
- LoL 站点的判定在服务端完成，插件按其棋盘列语义复刻，可能与站点细节有差异；
  `曾效力 / 英雄池` 这类集合属性以「有交集即一致」处理。
- 瓦罗兰特的判定口径参照 [瓦一把](https://wayiba.com) 页面：职责是集合属性（有交集算接近），
  「身份」把状态与是否一线队合成一格。

已知数据限制：

- CS 的 `team_history` 当前快照为空，所以「战队」只会 🟩 或 🟥。
- 足球的俱乐部按站点规则：五大联赛显示队名，其它统一显示「非五大联赛」，退役显示「已退役」。
- LoL 题库来自 Liquipedia 全量选手页；同名（如两个 Ace）不作为答案，所以答案池比题库少 34 条。
- 瓦罗兰特有 1 个重名标题 `Klaus`（2 条记录），同样只可猜、不作答案，故难档是 541 而非 543。
- 年龄、队伍、联赛均为快照值，转会后会有偏差，可用 `图鉴` 核对。

## 撸一把题库

数据来自 [Liquipedia](https://liquipedia.net/leagueoflegends) 的选手页（`Infobox player`），
字段是 ID、真名、出生日期、国籍、位置、状态、别名。想更新就重跑脚本：

```bash
python tools/build_lol_db.py              # 断点续抓，缓存在 data/.lol_liquipedia_cache.json
python tools/build_lol_db.py --limit 300  # 只抓前 300 页试水
python tools/build_lol_db.py --reset      # 清空进度重抓
```

脚本遵守 Liquipedia 的规则：请求间隔 ≥2 秒、带可识别的 User-Agent、只读公开页面。
国籍到中文名 / 大洲的映射写在脚本里，遇到没收录的国家会保留英文名、大洲留空。

> 为什么 LoL 只有 5 项属性：Liquipedia 的 infobox 里 `team` / `region` 大多为空
> （队伍与赛区靠站内的 Cargo 表渲染，API 不直接给），所以没有做「队伍」「赛区」格；
> `teams` 字段全量覆盖率不到 4%，放进去会让两两比较大面积假绿。

另：LoL 有 16 个重名标题（涉及 34 条记录），这些选手可以猜，但不会成为答案 ——
否则「猜中了」也可能判到同名的那位身上。

```bash
python tools/build_valorant_db.py              # 抓 wayiba 的 players.generated.json 生成题库
python tools/build_valorant_db.py --cache      # 用上次下载的缓存重算（data/.valorant_source_cache.json）
```

脚本只读站点公開的数据文件，热门人选直接用站点自带的 `popular` / `popularScore` 字段，
不自己拍脑袋排名。
