# 猜选手 · 弗一把 / 足一把 / 撸一把（AstrBot 插件）

在 QQ 群里玩三种「猜选手」：CS:GO / CS2 Major 选手、足球球员、LoL 职业选手。
一套对局骨架（开局、计时、提示、战绩、排行、存档）配三个题库，各自按自己的属性格给反馈。

仓库地址：<https://github.com/weadee/astrbot_plugin_friberg_guess>

## 三个题库

| 命令 | 题库 | 人数 | 机会 | 对比属性 |
| --- | --- | --- | --- | --- |
| `弗一把` | CS Major 选手 | 646 | 8 | 国家 · 赛区 · 战队 · 年龄 · 位置 · Major 冠军 · 出场 · 状态 |
| `足一把` | 足球球员 | 1141 | 10 | 国籍 · 联赛 · 俱乐部 · 位置 · 出生年 · 号码 · 欧冠 · 世界杯届数 · 世界杯冠军 |
| `撸一把` | LoL 职业选手 | 2427 | 8 | 位置 · 国家 · 大洲 · 年龄 · 状态 |

## 玩法示例

```
用户：足一把
Bot ：⚽ 足一把 · 猜足球球员
      难度：普通（核心球员 693 人）｜机会：10 次｜限时 30 分钟
      直接发选手名就能猜（大小写不限，可以只写前几个字母）
      其它指令：提示 · 放弃 · 战绩 · 排行 · 图鉴 <名字>
      其它题库：弗一把 · 撸一把
      🟩 完全一致　🟨 接近　🟥 不符　↑/↓ 答案更大/更小

用户：哈兰德
Bot ：第 1/10 猜｜哈兰德（Erling Haaland）
      🟨国籍 挪威　🟥联赛 英超
      🟥俱乐部 曼城　🟥位置 前锋
      🟥出生年 2000↓　🟥号码 9↓
      🟩欧冠 1　🟨世界杯 1↑
      🟥世界杯冠军 0↑
      还剩 9 次机会
```

`↑` / `↓` 表示**答案**比猜的这个数值更大 / 更小。

各题库的「接近」判定：

- **CS**：同赛区算国家接近；曾效力过答案所在战队算战队接近；年龄 ±3；冠军/出场 ±1
- **足球**：同大洲算国籍接近（双国籍互认直接算对）；出生年 ±2；号码 ±2；欧冠 ±1；世界杯届数 ±1；世界杯夺冠数必须一致
- **LoL**：位置、状态相同才算一致；国家相同为绿、同大洲为黄；年龄 ±2

## 指令

| 指令 | 说明 |
| --- | --- |
| `弗一把` / `足一把` / `撸一把` | 开一局，可带难度词 |
| 直接发选手名，或 `猜 xxx` | 提交一次猜测 |
| `提示` | 随机揭示一项属性，每局默认 2 次 |
| `放弃` | 结束本局并公布答案（也认「结束」「认输」） |
| `战绩` | 当前题库的胜场与平均猜测次数 |
| `排行` | 本群当前题库的胜场榜 |
| `图鉴 哈兰德` | 查选手资料（先查当前题库，找不到再翻其它题库） |
| `猜选手帮助` | 玩法说明 |

### 难度：易 / 中 / 难

三个题库共用一套难度词，开局时临时指定，或在配置里设默认值：

| 难度 | CS | 足球 | LoL |
| --- | --- | --- | --- |
| `易` | 知名选手 322 人 | 五大联赛热门球队 487 人 | 中韩选手 793 人 |
| `中` | 主流选手 384 人 | 五大联赛 925 人 | 现役选手 1929 人 |
| `难` | 全部 646 人 | 全部 1141 人（含非五大与退役） | 全部 2427 人（含退役） |

用法：`弗一把 难`、`足一把 易`、`撸一把 中`。旧难度词仍然兼容：`入门`→易、
`简单`→中、`普通`/`地狱`→难。

### 足一把的联赛范围

足一把还能把题库限制在某个联赛里，可以单独用，也可以和难度叠加（顺序随意）：

| 写法 | 范围 | 人数 |
| --- | --- | --- |
| `足一把` | 五大联赛（默认「中」） | 925 |
| `足一把 易` | 五大联赛里的热门球队 | 487 |
| `足一把 难` / `足一把 全部` | 全库，含沙特联 / 美职联 / 英冠 / 已退役 | 1141 |
| `足一把 英超` | 英超全部 | 317 |
| `足一把 西甲` / `德甲` / `意甲` / `法甲` | 该联赛全部 | 266 / 218 / 94 / 30 |
| `足一把 英超 易` | 英超热门球队 | 166 |
| `足一把 五大 难` | 五大联赛（不含其他联赛） | 925 |

「热门球队」是一份固定名单：英超八大（曼城、利物浦、阿森纳、曼联、切尔西、热刺、
纽卡斯尔联、阿斯顿维拉）、西甲八家（皇马、巴萨、马竞、塞维利亚、皇家社会、比利亚雷亚尔、
皇家贝蒂斯、瓦伦西亚）、德甲六队、意甲七队、法甲五队，共 31 支。名单写在
`main.py` 的 `BIG_CLUBS` 里，想调直接改。

### 仅私聊模式

配置里把「仅私聊可用」打开后，群里发指令和选手名都不会响应，只能私聊玩——
适合不想让群里被刷屏的场景。

群里和私聊都不需要唤醒前缀：`弗一把`、`/弗一把`、`猜 niko`、`提示` 都能直接用。
`提示` / `放弃` 在没有进行中对局时保持沉默，不会在群里乱触发。

## 安装

想省事就直接下 Releases 里的安装包（zip 内已含插件目录，解压即用）：

<https://github.com/weadee/astrbot_plugin_friberg_guess/releases/latest>

手动安装：

1. 把整个 `astrbot_plugin_friberg_guess` 文件夹放进 `AstrBot/data/plugins/`；
2. 在 WebUI「插件管理」里点重载（或重启 AstrBot）；
3. 插件配置里可调次数、限时、难度、各题库开关。

也可以在 WebUI 插件页填仓库地址安装，后续能直接在面板里更新：

```
https://github.com/weadee/astrbot_plugin_friberg_guess
```

无第三方依赖，纯标准库（抓题数据用的脚本在仓库外，插件运行时不联网）。

## 配置项（`_conf_schema.json`）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `difficulty` | `中` | 默认难度：易 / 中 / 难 |
| `private_only` | 关 | 仅私聊可用，群里不响应 |
| `max_attempts` | 0 | 0 = 按题库默认（CS 8 / 足球 10 / LoL 8）；填正数则统一 |
| `timeout_minutes` | 30 | 单局限时，超时公布答案；0 不限时 |
| `enable_cs` / `enable_football` / `enable_lol` | 开 | 分题库开关 |
| `free_text_guess` | 开 | 允许直接发名字猜 |
| `enable_hint` / `hint_limit` | 开 / 2 | 提示功能 |
| `show_legend` | 开 | 第一次猜测附带图例 |
| `at_sender` | 开 | 群聊反馈时 @ 人 |

## 数据

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `data/players.json` | 646 位 CS Major 选手 | 社区整理版本（快照 2026-08-04） |
| `data/football_players.json` | 1141 位足球球员 | 足一把 `players.js`（2026-27 赛季初） |
| `data/lol_players.json` | LoL 职业选手 | [Liquipedia](https://liquipedia.net/leagueoflegends) 选手页 Infobox，用 `tools/build_lol_db.py` 生成 |

- CS 判定口径参照开源项目 [csgofriberg](https://github.com/shnlfriberg/csgofriberg)（AGPL-3.0）。
- 足球判定口径参照 [足一把](https://www.zuyiba.net) 页面里的 `compare` 实现。
- LoL 站点的判定在服务端完成，插件按其棋盘列语义复刻，可能与站点细节有差异；
  `曾效力 / 英雄池` 这类集合属性以「有交集即一致」处理。

已知数据限制：

- CS 的 `team_history` 当前快照为空，所以「战队」只会 🟩 或 🟥。
- 足球的俱乐部按站点规则：五大联赛显示队名，其它统一显示「非五大联赛」，退役显示「已退役」。
- LoL 题库靠关键词扫描抓取，冷门选手可能缺失；想补就替换 `data/lol_players.json` 后重载。
- 年龄、队伍、联赛均为快照值，转会后会有偏差，可用 `图鉴` 核对。

## 撸一把题库

数据来自 [Liquipedia](https://liquipedia.net/leagueoflegends) 的选手页（`Infobox player`），
字段是 ID、真名、出生日期、国籍、位置、状态、别名。想更新就重跑脚本：

```bash
python tools/build_lol_db.py              # 断点续抓，缓存在 data/.lol_liquipedia_cache.json
python tools/build_lol_db.py --limit 300  # 只抓前 300 页试水
python tools/build_lol_db.py --reset      # 清空进度重抓
```

脚本遵守 Liquipedia 的规则：请求间隔 ≥2 秒、带可识别的 User-Agent、只读公开页面。
国籍到中文名 / 大洲的映射写在脚本里，遇到没收录的国家会保留英文名、大洲留空。

> 为什么 LoL 只有 5 项属性：Liquipedia 的 infobox 里 `team` / `region` 大多为空
> （队伍与赛区靠站内的 Cargo 表渲染，API 不直接给），所以没有做「队伍」「赛区」格；
> `teams` 字段全量覆盖率不到 4%，放进去会让两两比较大面积假绿。
