# 猜选手 · 弗一把 / 足一把 / 撸一把 / 瓦一把（AstrBot 插件）

在 QQ 群里玩四种「猜选手」：CS:GO / CS2 Major 选手、足球球员、LoL 职业选手、瓦罗兰特职业选手。
一套对局骨架（开局、计时、提示、战绩、排行、存档）配四个题库，各自按自己的属性格给反馈。

仓库地址：<https://github.com/weadee/astrbot_plugin_friberg_guess>

| `撸一把` | LoL 职业选手 | 386 | 8 | 位置 · 国家 · 大洲 · 战队 · 年龄 · S 赛参赛 · S 赛冠军 · 状态 |

### 棋盘排版

**一行两项，放不下就这一项单独占一行。**

手机放大字号后一行只放得下十六七个汉字，以前塞满三格会被聊天窗硬折断（`VCT / EMEA` 那样断在词中间）。
现在的规则是：

- 一行两项，每行控制在 32 个半角单位（约 16 个汉字）以内，放大字号也不会折行
- 两项加起来放不下（例如 `赛区 VCT EMEA` 配 `大师赛参赛 7↓`），第二项就挪到下一行，
  宁可多一行，也不让聊天窗把字切开
- 开局文案、图鉴、提示、战绩、排行同样按这个宽度排版，长句在标点处断开

各题库的「接近」判定：

- **CS**：同赛区算国家接近；曾效力过答案所在战队算战队接近；年龄 ±3；冠军/出场 ±1
- **足球**：同大洲算国籍接近（双国籍互认直接算对）；出生年 ±2；号码 ±2；欧冠 ±1；世界杯届数 ±1；世界杯夺冠数必须一致
- **LoL**：位置、状态相同才算一致；国家相同为绿、同大洲为黄；年龄 ±2
- **瓦罗兰特**：国籍同大洲为黄；战队同赛区为黄；身份要「状态 + 是否一线队」两项都对才绿
  （只要有一方退役就只比状态）；职责完全相同为绿、有交集为黄；大师赛参赛 ±2、冠军赛参赛 ±1；
  年龄与两个冠军数只 ↑/↓ 不给黄

| 指令 | 说明 |

### 难度：易 / 中 / 难

四个题库共用一套难度词，开局时临时指定，或在配置里设默认值：

| 难度 | CS | 足球 | LoL | 瓦罗兰特 |
| --- | --- | --- | --- | --- |
| `易`（默认） | 最火 200 人 | 知名 300 人（含退役与小联赛巨星） | 热门 200 人 | 热门 150 人（含退役、自由人） |
| `中` | 主流选手 384 人 | 五大联赛 925 人 | 现役 304 人 | 有国际赛履历 314 人 |
| `难` | 全部 646 人 | 全部 1141 人（含非五大与退役） | 全部 386 人（含知名退役） | 全部 541 人 |

用法：`弗一把 难`、`足一把 易`、`撸一把 中`、`瓦一把 难`。旧难度词仍然兼容：`入门`→易、
`简单`→中、`普通`/`地狱`→难。

**难度只管「答案」，不管「你能猜谁」**：题库永远是完整的，难度决定答案从多大的池子里抽。

| | 题库（都能猜） | 易（默认） | 中 | 难 |
| --- | --- | --- | --- | --- |
| 弗一把 | 646 | 200 | 384 | 646 |
| 足一把 | 1141 | 300 | 925 | 1141 |
| 撸一把 | 386 | 200 | 304 | 386 |
| 瓦一把 | 543 | 150 | 314 | 541 |

也就是说：`足一把` 的答案来自 300 人，但池外那 841 人照样能提交、照样有完整棋盘反馈，
只是不会成为答案。同名选手（撸一把有 16 个重名，如两个 Ace；瓦一把有 1 个，`Klaus`）
不作为答案，避免猜中了判到另一个人身上。

### 弗一把的默认池：最火 200 人

不带难度发 `弗一把`，**答案**从「最火 200 人」里出；**题库仍是 646 人** —— 猜谁都可以，
池外那 446 人照样能提交、照样有棋盘反馈，只是不会成为答案。

- **135 位点名名单**：s1mple、ZywOo、NiKo、device、dupreeh、olofmeister、GeT-RiGhT、f0rest、
  NEO、markeloff、coldzera、FalleN、karrigan、donk、m0NESY、Twistzz、EliGE、Stewie2K……

### 仅私聊模式

配置里把「仅私聊可用」打开后，群里发指令和选手名都不会响应，只能私聊玩——
适合不想让群里被刷屏的场景。

群里和私聊都不需要唤醒前缀：`弗一把`、`/弗一把`、`猜 niko`、`提示` 都能直接用。
`提示` / `放弃` 在没有进行中对局时保持沉默，不会在群里乱触发。

## 安装

想省事就直接下 Releases 里的安装包（zip 内已含插件目录，解压即用）：

<https://github.com/weadee/astrbot_plugin_friberg_guess/releases/latest>

手动安装：

1. 把整个 `astrbot_plugin_friberg_guess` 文件夹放进 `AstrBot/data/plugins/`；
2. 在 WebUI「插件管理」里点重载（或重启 AstrBot）；
3. 插件配置里可调次数、限时、难度、各题库开关。

也可以在 WebUI 插件页填仓库地址安装，后续能直接在面板里更新：

```
https://github.com/weadee/astrbot_plugin_friberg_guess
```

无第三方依赖，纯标准库（抓题数据用的脚本在仓库外，插件运行时不联网）。

## 配置项（`_conf_schema.json`）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `difficulty` | `易` | 默认难度：易 / 中 / 难（只影响答案池，不影响能猜谁） |
| `private_only` | 关 | 仅私聊可用，群里不响应 |
| `max_attempts` | 0 | 0 = 按题库默认（CS 8 / 足球 10 / LoL 8 / 瓦一把 8）；填正数则统一 |
| `timeout_minutes` | 30 | 单局限时，超时公布答案；0 不限时 |
| `enable_cs` / `enable_football` / `enable_lol` / `enable_valorant` | 开 | 分题库开关 |
| `free_text_guess` | 开 | 允许直接发名字猜 |
| `enable_hint` / `hint_limit` | 开 / 2 | 提示功能 |
| `history_team` | **关** | 猜的队伍是该选手效力过的老东家时，「战队」格判 🟨 接近；关掉则只有同队才绿、其余一律红（弗一把与撸一把有历史战队数据） |
| `show_legend` | 开 | 第一次猜测附带图例 |
| `at_sender` | 开 | 群聊反馈时 @ 人 |

  `曾效力 / 英雄池` 这类集合属性以「有交集即一致」处理。
- 瓦罗兰特的判定口径参照 [瓦一把](https://wayiba.com) 页面：职责是集合属性（有交集算接近），
  「身份」把状态与是否一线队合成一格。

已知数据限制：

- CS 的 Major 冠军 / 出场次数沿用 2026-08-04 的社区快照；Liquipedia 上这两项是动态模板
  （`{{Player achievements table}}`）生成的，不逐页展开就拿不到，所以没有跟着刷新。
- 足球的俱乐部按站点规则：五大联赛显示队名，其它统一显示「非五大联赛」，退役显示「已退役」。
- LoL 现在只收「现役 + S 赛履历厚的退役」，所以库比原来小很多（386 人）；另一半现役选手没有战队数据（自由人/替补），「战队」格显示 `—`。
- 瓦罗兰特有 1 个重名标题 `Klaus`（2 条记录），同样只可猜、不作答案，故难档是 541 而非 543。
- 年龄、队伍、联赛均为快照值，转会后会有偏差，可用 `图鉴` 核对。

## 弗一把题库更新（转会）

转会、退役、转教练都会让旧快照失真，所以加了刷新脚本：

```bash
python tools/enrich_cs_db.py               # 抓 Liquipedia 并写 data/players.json
python tools/enrich_cs_db.py --probe       # 只看变动统计，不写文件
python tools/enrich_cs_db.py --fresh       # 丢掉缓存重新抓一遍
```

抓的是 [Liquipedia CS2 维基](https://liquipedia.net/counterstrike) 选手页的 `Infobox player`，
只更新会随时间变的字段：**现队、在役状态、角色、年龄、历史战队**。
Major 冠军 / 出场次数沿用原快照（见上面的已知限制）。

### 抓错人的几道防线

同名选手很多（两个 Uzi、两个 niko），脚本宁可不更新也不串号：

- 页面 ID 与选手名对不上 → 跳过
- 同名条目的国籍与原库标注不符 → 跳过
- 年龄和原库差 4 岁以上 → 跳过
- **原东家不在该页面的队伍履历里 → 跳过**
- 抓到消歧义页（`{{for|the Israeli player|xertioN}}`）就用搜索找真正的选手页，再按上面几条校验
- 现队只认 Infobox 的 `team` 字段；Liquipedia 的 `ex-队名` 表示已离队，不算现队
- `Active` 但没写队伍的老将不判成「复出」，保留原库的退役状态

## 撸一把题库

两段数据拼起来：

1. **[guessassin](https://guessassin.xyz)** 的选手接口（`/api/players/CN_KR` 与 `/api/players/GLOBAL`）
   给出「当前战队、历史战队、S 赛出场次数、S 赛冠军数、赛区、位置、年龄、出生地」；
   退役老将通过 `/api/feedback/search-players` + `player-detail` 按 ID 补。
2. **[Liquipedia](https://liquipedia.net/leagueoflegends)** 的选手页补真名、别名、中文国籍。

```bash
python tools/build_lol_db.py        # 重建 Liquipedia 基底（data/lol_players.liquipedia.json）
python tools/enrich_lol_db.py       # 合并战队 / S 赛数据，写 data/lol_players.json
python tools/enrich_lol_db.py --probe   # 只看统计不写文件
```

选题规则：

- **只收现役**（最后出场年份 ≥ 2025），退役只留 **S 赛履历厚的**（S 赛冠军 / 出场次数达到门槛），
  共 386 人：现役 304、退役 82。
- 只挂教练头衔的不算选手，直接排除。

## 瓦一把题库

数据来自 [瓦一把](https://wayiba.com) 站点公开的 `players.generated.json`，字段是 ID、中文名、
真名、国籍、赛区、战队、职责、年龄、大师赛/冠军赛参赛与夺冠次数。想更新就重跑脚本：

```bash
python tools/build_valorant_db.py              # 抓 wayiba 的 players.generated.json 生成题库
python tools/build_valorant_db.py --cache      # 用上次下载的缓存重算（data/.valorant_source_cache.json）
```

脚本只读站点公開的数据文件，热门人选直接用站点自带的 `popular` / `popularScore` 字段，
不自己拍脑袋排名。
